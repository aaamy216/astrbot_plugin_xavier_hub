# Xavier Hub

沈星回心声系统（AstrBot 原生面板 + 独立前端服务）。模型在回复末尾使用 `<xt>` 标签输出 JSON，本插件解析后全量持久化写入状态，并在网页端提供实时展示、历史回顾、收藏、便签与三餐灵感。

## 安装

1. 把本目录放到 AstrBot 的 `data/plugins/` 下  
2. 仪表盘 → 插件 → 启用 / 重载 **小回的心声 (Xavier Hub)**  
3. 查看心声：
   - **方式一（推荐·面板直达）**：AstrBot 管理面板左侧点击 **「插件页面」** → **「小回的心声」**，开箱即看，自适应面板；
   - **方式二（独立网页）**：在插件配置中开启 `visualizer_enabled`，浏览器访问 `http://服务器IP:端口`（默认端口 `8765`）。

## 核心配置

| 配置项 | 说明 | 默认值 |
|---|---|---|
| `target_user_id` | 只对这个用户启用心声。**QQ 场景填对方 QQ 号**；其它平台填该平台用户 ID。留空=不限制（请谨慎） | `""` |
| `visualizer_enabled` | 是否启用独立的 HTTP Web 服务端口（若仅在 AstrBot 面板内查看可保持关闭） | `false` |
| `visualizer_port` | 独立前端服务端口，默认 `8765`（请自行选择未占用端口） | `8765` |
| `visualizer_host` | 独立前端服务监听地址，`0.0.0.0` 允许外网访问，`127.0.0.1` 仅本地访问 | `0.0.0.0` |
| `thoughts_instruction` | 注入给模型的心声模板，**字段名要和下面一致** | 自定义模板 |
| `thought_fields` | 心声字段，逗号分隔 | `情绪,兔在想,兔悄悄,兔心愿,无厘头` |

改配置后 **重载插件** 生效。

## 心声上下文留存机制

在插件配置的 `thoughts_history_mode` 中选择心声怎么参与后续对话：

| 模式 | 进对话历史 | 注入系统提示词 | 网页能看到 | 聊天框能看到 |
|---|---|---|---|---|
| `last_n`（推荐） | 否 | 当前对话最近 N 轮 | 能 | 不能 |
| `none` | 否 | 否 | 能 | 不能 |
| `all` | 是 | 否 | 能 | 不能 |

`N` 由 `thoughts_history_n` 决定，默认 3，填 0 不注入。

**心声是怎么被挡在上下文外面的**

AstrBot 从 4.11 开始，会先把模型回复放进本轮的消息列表，再触发 `on_llm_response`，最后把这个消息列表存成对话历史。在 `on_llm_response` 里改文本已经来不及了。

0.4.0+ 改为在 AstrBot 的 Runner 拿到模型回复、还没组装成上下文消息的时候处理：先把心声解析存盘（网页的数据从这里来），`none` / `last_n` 再把 `<xt>` 从回复里拿掉，Runner 随后用干净的文本组装上下文。整个过程不修改 `req.contexts`，也不回头改已经保存的历史。带工具调用的那一轮、流式输出的分片，也在这一步一起处理。

这一步依赖 AstrBot 的内部方法 `ToolLoopAgentRunner._iter_llm_responses_with_fallback`（以及 `_complete_with_assistant_response`）。发 `/xavier_hub_health` 能看到拦截是否生效。

**会话隔离**

每条心声都记着它来自哪个会话、哪段对话（存的是哈希，网页接口不会暴露 QQ 号或群号）。`last_n` 只注入当前会话、当前对话里的心声：

- 私聊和群聊互相看不到对方的心声
- `/new`、`/reset` 开了新对话之后，从头开始计
- `/switch` 切回旧对话，注入的是那段对话自己的心声
- 便签提醒也只带当前会话心声上的便签
- `/xt` 显示的是当前会话最近的一条

## 前端特性

- **双端支持**：既能无缝嵌入 AstrBot 4.11+ 管理后台「插件页面」，也能作为独立 Web 站点全屏运行、添加到手机主屏幕 (PWA)；
- **实时卡片**：展示小回的情绪状态、内心想法、悄悄话、心愿以及无厘头碎碎念；
- **历史回溯**：时间轴滚动浏览历史心声，支持删除与筛选；
- **悄悄喜欢**：整条心声或单独字段收藏，记录动心瞬间；
- **心声便签**：点击心声添加便签回复，双向互动反馈；
- **灵感三餐**：结合时间与心境生成一日三餐灵感。

## 可选配置

- `thoughts_history_mode`：心声历史留存模式（`last_n` / `none` / `all`）  
- `thoughts_history_n`：`last_n` 模式下系统提示词回顾的心声轮数（默认 3，0 为不注入，最多 20）  
- `session_whitelist`：只在指定会话生效；留空=不限制会话（仍受 `target_user_id` 约束）  
- `ext_panel_enabled`：开启后才显示「手机」页，并读取手机推送 / 闹钟等跨插件数据（默认关）  
- `note_notify_enabled` / `note_notify_umo` / `bot_qq_id`：便签通知相关  
- `meals_enabled`：一日三餐生成与灵感参考注入  

## 命令

- `/xt` — 查看当前会话最新一条心声  
- `/xavier_notes` — 查看对方贴在自己心声上的便签  
- `/xavier_hub_health` — 查看插件运行状态：AstrBot 版本、心声模式、上下文拦截是否生效等  
- `/小回吃什么` — 查看或补生成今日三餐  
- `/小回重新吃` — 强制重想今日三餐  

## 开发架构

- 插件页面入口：`pages/thoughts/index.html`（适配 AstrBot 原生管理面板）
- 独立前端服务：`hub_visualizer.html`（沈星回专属淡紫磨砂视觉系统）
- 后端逻辑：`main.py`（上下文清洗拦截、HTTP 服务、三餐调度与便签处理）
- 配置描述：`_conf_schema.json`
- 元数据：`metadata.yaml`
